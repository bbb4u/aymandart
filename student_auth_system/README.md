# نظام المصادقة الطلابي المتكامل (Student Authentication System)

مشروع تطبيقي مبني بلغة **Dart و Flutter الخالصة بنسبة 100% دون أي حزم أو مكتبات خارجية**، بالاعتماد على **نمط MVC المعزز بنمط المستودع (Repository Pattern)**.

---

## 🏛️ الهيكل المعماري للمشروع (Architecture Structure)

```text
lib/
├── main.dart                          # نقطة انطلاق التطبيق وإعداد السمة وRTL
├── models/
│   ├── user_model.dart                # كائن بيانات الطالب (UserModel)
│   └── auth_requests.dart             # نماذج الطلبات (Login, Register, Reset)
├── repositories/
│   ├── auth_repository.dart           # العقد التجريدي (Interface / Contract)
│   └── auth_repository_impl.dart      # تطبيق المستودع بمحاكاة الشبكة والتأخير
├── controllers/
│   ├── auth_controller.dart           # متحكم إدارة الحالة عبر ChangeNotifier
│   └── auth_scope.dart                # حقن الحالة عبر InheritedNotifier الأصلي
├── utils/
│   └── form_validators.dart           # دوال التحقق النقية (Pure Validation Functions)
└── views/
    └── auth/
        ├── login_page.dart            # شاشة تسجيل الدخول
        ├── register_page.dart         # شاشة إنشاء حساب جديد
        ├── forgot_password_page.dart  # شاشة استعادة كلمة المرور
        └── reset_password_page.dart   # شاشة تعيين كلمة المرور الجديدة
```

## 📋 شروط التحقق المطبقة (Validation Rules)

1. **تسجيل الدخول:**
   - المعرف: غير فارغ، ≥ 5 خانات.
   - كلمة المرور: ≥ 6 محارف، مع زر إظهار/إخفاء.
2. **إنشاء الحساب:**
   - الاسم الكامل: ≥ 3 محارف.
   - الرقم الأكاديمي: أرقام حصراً، 9-10 خانات.
   - البريد الجامعي: صيغة Regex قياسية للبريد.
   - كلمة المرور: ≥ 8 محارف + رقم واحد + حرف كبير (A-Z).
   - تأكيد كلمة المرور: مطابقة تامة 100%.
   - الموافقة على الشروط الأكاديمية: إلزامي.
3. **استعادة وتحديث كلمة المرور:**
   - بطاقة توجيهية تشرح الآلية.
   - رمز OTP: مكون من 6 أرقام رقمية حصراً.
   - نافذة تأكيد نجاح وعودة لشاشة الدخول.
